# Docker Simplifier v2 — Roadmap

## Phase 0: Specification
Deliver AGENTS.md, SPEC.md, ARCHITECTURE.md, ROADMAP.md, TASKS.md.

## Phase 1: Safe foundation
Baseline, modularization, terminal guard, secure argument execution, async event/task loop, config loader, safety policies.
Exit: responsive TUI, no shell interpolation, Docker-unavailable handling.

## Phase 2: Container-first MVP
Dashboard, resource table, filters, inspect, start/stop/restart, live logs, stats and health.
Exit: daily-use Docker container workflow.

## Phase 3: Compose, images and contexts
Compose projects and profiles, images, SSH contexts, themes and keybindings.
Exit: reliable multi-project/multi-host Docker administration.

## Phase 4: Operations
Networks, volumes, events, monitoring, safe cleanup and optional backups.
Exit: production-aware maintenance workflows.

## Phase 5: CLI and release
Noninteractive JSON CLI, tests, CI, documentation and cross-platform binaries.
Exit: versioned, installable release.
