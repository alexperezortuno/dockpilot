# Dockpilot v0.5.0-beta.1

## Summary

First public beta candidate of Dockpilot, a keyboard-first Rust TUI for Docker Engine and Docker Compose.

## Available

- Container, image, network, volume, project, dashboard, and help views.
- Docker context selection and read-only policy.
- Guarded lifecycle operations and bounded logs.
- Compose commands with explicit working directories.
- Metrics, health, events, alerts, themes, filtering, command palette, and background refresh.
- Conditional rendering, stable selection, cancellable tasks, and bounded output.

## Installation

Download the archive for your platform, verify `SHA256SUMS.txt`, extract it, and run `dockpilot --version`. See [installation](../installation.md).

## Platforms

The release workflow builds Linux x86_64, macOS Apple Silicon, macOS Intel, and Windows x86_64. A build is not a platform validation; release notes must be updated with the platforms actually exercised before publication.

## Known limitations

- Docker Engine and Docker Compose are required for Docker operations.
- Docker integration testing is opt-in and requires a reachable Engine.
- No Podman, Kubernetes, web dashboard, or generic engine support.
- The first beta has no signed installer and no selected open-source license file yet.

## Security

Docker socket access can grant root-equivalent privileges. Read [security](../security.md) before installation.

## Bug reports

Use the repository bug report template. Include Dockpilot version, OS/architecture, Docker version, reproduction steps, and sanitized logs. Never include credentials or private keys.
